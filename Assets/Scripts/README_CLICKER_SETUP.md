# Инструкция по настройке кликер-механики в Unity 6 (6000.0.6f1)

## Созданные скрипты

### 1. `ClickerController.cs` — Основной контроллер игры
Управляет монетами, автогенерацией, улучшениями и сохранением.

### 2. `CharacterClickHandler.cs` — Обработчик кликов по персонажу
Добавляет монеты при клике на персонажа.

### 3. `AutoCoinGenerator.cs` — Автоматическое начисление монет
Каждую секунду вызывает начисление монет в секунду.

---

## Настройка в редакторе Unity

### 1. Создайте пустой GameObject для контроллера
- В Hierarchy: ПКМ → **Create Empty**
- Название: `ClickerController`
- Добавьте компонент: **Add Component** → `Clicker Controller` (скрипт `ClickerController`)

### 2. Настройте UI ссылки в инспекторе `ClickerController`

Перетащите соответствующие объекты из сцены `Game`:

| Поле в инспекторе | Объект в сцене | Компонент |
|------------------|----------------|-----------|
| **Coins Per Second Text** | `param/в секунду` | `TextMeshProUGUI` (монеты в сек: `1.5K/s`) |
| **Upgrade Cost Text** | `LevelUp/ButtunLevelUp/500/1,5k` | `TextMeshProUGUI` (стоимость улучшения: `500`, `1.5K`...) |
| **Upgrade Reward Text** | *Создайте новый Text на кнопке* | `TextMeshProUGUI` (показывает +X за улучшение) |
| **Progress Bar Text** | *Создайте Text на прогресс-баре* | `TextMeshProUGUI` (показывает "текущие / макс": `500 / 1.5K`) |
| **Progress Bar** | `progress` | `Image` (рекомендуется `Image Type = Sliced`; также поддерживается `Filled`) |
| **Bar Background** | `BAR` | `RectTransform` (фон прогресс-бара для масштабирования) |
| **Upgrade Button** | `LevelUp/ButtunLevelUp` | `Button` |

### 3. Настройте кликабельного персонажа
- Найдите в сцене: `MainContent/Image` (это ваш персонаж)
- Добавьте компонент: **Add Component** → `Character Click Handler` (скрипт `CharacterClickHandler`)
- Убедитесь, что у объекта есть `Image` с включенным `Raycast Target = true`
- В поле `Clicker Controller` перетащите объект `ClickerController`

### 4. Добавьте автогенерацию монет
- На том же объекте `ClickerController` добавьте компонент: **Add Component** → `Auto Coin Generator` (скрипт `AutoCoinGenerator`)
- В поле `Clicker Controller` перетащите тот же объект `ClickerController`
- `Tick Interval` оставьте `1` (1 секунда)

### 5. Настройка кнопки улучшения
- Найдите: `LevelUp/ButtunLevelUp`
- **Создайте текст наград на кнопке** (если нет):
  - ПКМ на `ButtunLevelUp` → **UI** → **Text - TextMeshPro**
  - Название: `UpgradeRewardText`
  - Текст: `+1`
  - Позиционируйте на кнопке
- У компонента `Button` в поле **On Click ()**:
  - Нажмите `+`
  - Перетащите объект `ClickerController`
  - Выберите: `ClickerController` → `TryUpgrade()`

### 6. Настройка прогресс-бара
- Объект `progress` → компонент `Image`
- `Image Type` = **Sliced** (границы спрайта сохраняются при изменении ширины)
- Для варианта **Filled** используйте `Fill Method` = **Horizontal**, `Fill Origin` = **Left**
- Для `Sliced` настройте границы спрайта в Sprite Editor
- В инспекторе `ClickerController` поле **Bar Background** = перетащите объект `BAR`
- В `Awake` прогресс-бар автоматически растягивается на весь размер `BAR`

### 7. Текст прогресс-бара (опционально)
- ПКМ на `progress` → **UI** → **Text - TextMeshPro**
- Название: `ProgressBarText`
- Позиционируйте по центру или над прогресс-баром
- В инспекторе `ClickerController` поле **Progress Bar Text** = перетащите созданный текст
- Будет показывать: `1.5K / 1.5M` (текущие монеты / макс. значение прогресс-бара)

### 8. Реклама Яндекс Игр через YG2
- Убедитесь, что плагин `YG2` подключён и в проекте включён модуль `InterstitialAdv`
- В `ClickerController` реклама запускается автоматически, когда монеты впервые пересекают половину значения `Progress Bar Max Value`
- Показ выполняется только на WebGL-сборке Яндекс Игр, в редакторе он не срабатывает

## Настройки баланса (в инспекторе ClickerController)

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| Coins Per Click | 10 | Монет за клик |
| Coins Per Second | 0 | Начальные монеты в секунду |
| Base Upgrade Cost | 500 | Стоимость 1-го улучшения |
| Upgrade Cost Multiplier | 1.15 | Во сколько раз дорожает каждое следующее (+15%) |
| Upgrade Coins Per Second Increase | 1 | На сколько увеличивается монет/сек за улучшение (показывается как +X на кнопке) |
| Progress Bar Max Value | 1500 | Макс. значение для заполнения шкалы (визуальная отметка) |
| **Cap Coins At Max Value** | **false** | **Если true — монеты жёстко ограничены макс. значением** |
| **Enable Auto Save** | **true** | **Отключите для тестов (нет автосохранения каждые 5 сек)** |
| **Reset On Start** | **false** | **Если true — чистит сохранение при старте, использует значения инспектора** |

## Сохранение/Загрузка
- Игра автоматически сохраняется каждые 5 секунд (если включено)
- Сохраняется при минимизации (`OnApplicationPause`)
- Сохраняется при выходе (`OnApplicationQuit`)
- Данные хранятся в `PlayerPrefs` (кроссплатформенно)

### Отключение сохранения для тестов
1. В инспекторе `ClickerController` снимите галочку **Enable Auto Save**
2. Или поставьте галочку **Reset On Start** — очистит PlayerPrefs при каждом запуске и использует значения из инспектора
3. Или из кода: `clickerController.SetAutoSaveEnabled(false);`

## Проверка работоспособности

1. Запустите сцену `Game`
2. Кликайте по персонажу — монеты увеличиваются на 10
3. Шкала прогресса заполняется относительно фона `BAR`
4. Текст на прогресс-баре показывает: `500 / 1.5K` (текущие / макс)
5. Нажмите кнопку улучшения (если хватает монет) — монеты/сек увеличится, на кнопке покажет +X
6. Подождите 1 секунду — монеты начнут капать автоматически
7. При больших числах везде включается форматирование: `1K`, `1.5M`, `2.3B`
8. Перезапустите сцену — прогресс сохранится (если включено)

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Клик не работает | Проверьте `Raycast Target = true` на Image персонажа; убедитесь, что Canvas имеет `Graphic Raycaster` |
| Кнопка не нажимается | Проверьте `Interactable = true` у Button; назначьте `OnClick` событие |
| Текст не обновляется | Проверьте назначение полей в инспекторе `ClickerController` |
| Прогресс-бар не заполняется | Убедитесь, что назначены `Progress Bar` и `Bar Background`; для `Filled` проверьте `Fill Method`, а для `Sliced` — границы спрайта в Sprite Editor |
| Ошибки компиляции | Убедитесь, что подключены `UnityEngine.UI` и `TMPro` (using) |
| Монеты превышают макс. значение | Включите `Cap Coins At Max Value` для жёсткого ограничения |
| Числа вылезают за границы текста | Форматирование K/M/B включено автоматически в `FormatNumber()` |

## Архитектура для расширения

- `ClickerController` — синглтон-подобный менеджер состояния
- Легко добавить новые улучшения: создайте метод `BuyUpgrade(cost, reward)` и новые кнопки
- Для престижа/сброса используйте `ResetGame()`
- Для ивентов добавьте `UnityEvent<long> OnCoinsChanged` в `ClickerController`
